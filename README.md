# XP Investimentos — Landing Page Conceito

Landing page conceitual moderna e responsiva inspirada na **XP Investimentos**, desenvolvida com HTML5, Tailwind CSS e efeitos visuais imersivos.

---

## 🚀 Tecnologias Utilizadas

- **HTML5 & Vanilla JS**
- **Tailwind CSS v4**
- **Bootstrap Icons**
- **Lenis Scroll / Locomotive Scroll**

---


---

## 💻 Como Executar o Projeto Localmente

1. Clone o repositório:
   ```bash
   git clone https://github.com/<seu-usuario>/<seu-repositorio>.git
   cd Banco-XP
   ```

2. Instale as dependências:
   ```bash
   npm install
   ```

3. Para compilar o Tailwind CSS em modo de desenvolvimento (watch):
   ```bash
   npm run dev
   ```

4. Abra `dist/index.html` no seu navegador favorito.
